Upgrading

The engine is Product Council v3.7.3.

Upgrade packs never write or delete anything under context/, sessions/, analysis/, diagrams/, metrics/, reports/, lessons-log/, handoffs/ or personas/. They back up every file they change, and they list any file your team customised.

  1. Upgrade the base firstApply the pack on a branch of the retail base, run python3 scripts/selftest.py and the evals, then merge.
  2. Then each client projectApply the same pack to each project on its own branch. A project made with "Use this template" has no shared git history with the base, so it takes the pack, not a merge. Its own context, sessions and personas are left alone.

Detail is in UPGRADE.md and CHANGELOG.md.
